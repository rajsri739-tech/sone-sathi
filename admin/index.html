☁️ MongoDB Atlas Free Database Setup Guide
Render Free Web Service 15 मिनट इनएक्टिविटी के बाद स्लीप हो जाता है और लोकल फाइल्स वाइप हो जाती हैं। MongoDB Atlas (M0 Free Cluster) लाइफटाइम फ्री है और इससे आपकी कोई भी दुकान, लाइसेंस या बैकअप कभी डिलीट नहीं होगा।
1
MongoDB Atlas अकाउंट बनाएं
mongodb.com/atlas/register ↗ पर फ्री अकाउंट बनाएं और M0 Free Tier क्लस्टर चुनें (₹0/Lifetime).
2
Database User & Network IP सेट करें
• Database Access टैब में नया यूजर बनाएं (उदा. Username: admin, Password: apna_password)
• Network Access टैब में Add IP Address पर क्लिक करके 0.0.0.0/0 (Allow Access from Anywhere) सेलेक्ट करें।
3
Connection String कॉपी करें
"Connect" बटन दबाएं ➔ "Drivers" (Node.js) चुनें ➔ Connection String कॉपी करें:
mongodb+srv://admin:<password>@cluster0.xxxx.mongodb.net/?retryWrites=true&w=majority * <password> की जगह अपना असली पासवर्ड डालें।
4
Render Dashboard में Environment Variable जोड़ें
• Render Dashboard ↗ में अपनी Sone Sathi Web Service खोलें।
• बाएँ मेनू से "Environment" टैब पर जाएं।
• "Add Environment Variable" पर क्लिक करें:
  Key: MONGODB_URI
  Value: mongodb+srv://admin:pass@cluster0...
• "Save Changes" पर क्लिक करें। Render अपने-आप री-डिप्लॉय कर लेगा और स्टेटस 🟢 Permanent Cloud हो जाएगा!
